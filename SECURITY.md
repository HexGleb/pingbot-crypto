# Reporting a security problem

Please report it privately: on this repository's **Security** tab, choose **Report a vulnerability**. Don't open a
public issue for it.

Say what you found, how to reproduce it, and which version (tag) you looked at. Please give us 90 days to ship a
fix before you publish. We will credit you in the release notes unless you'd rather not be named.

In scope: everything in this repository, and how the PingBot app and bridge use it (SPEC.md). The known limits in
SPEC.md, section 6, are already documented, but ideas to close them are welcome.
